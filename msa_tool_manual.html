Step 1

MSA 분석 모듈 선택 — "어떤 측정시스템을 검증하나요?"

측정 방식과 목적에 따라 6가지 중 하나를 고릅니다. 각 타일에 한 줄 설명이 붙어 있어 헷갈리면 바로 확인할 수 있습니다.

🔬 MSA 분석 모듈 선택
① Gage R&R 교차연구 ② Gage R&R 내포연구 ③ 유형3 연구 ④ 계수형 합치도 분석 ⑤ Type4 선형성·치우침 연구 ⑥ 유형1 Gage 연구

v2.0 — 모듈 선택이 타일 목록으로 바뀌어 각 항목에 설명이 함께 표시됩니다. 화면이 넓으면 2열, 좁으면 1열로 배치되며, 선택한 타일은 파란 테두리로 강조됩니다.

① 교차 (Crossed)

여러 측정자 × 같은 부품 세트

모든 측정자가 같은 부품 전체를 반복 측정할 수 있을 때 사용하는 표준 Gage R&R입니다.

이럴 때 사용 → "측정자 3명이 같은 부품 10개를 각 3회씩 측정 가능"
② 내포 (Nested)

파괴검사 등 부품 재사용 불가

측정하면 샘플이 파괴/소모되어, 측정자마다 서로 다른 부품을 측정해야 할 때 사용합니다.

이럴 때 사용 → "인장강도 시험처럼 한 번 측정하면 시료가 파괴됨"
③ 유형3 NEW

측정자 영향이 없는 설비

자동측정기·비전검사기처럼 사람이 결과에 영향을 주지 않는 설비. 재현성 항 없이 반복성만 평가합니다.

이럴 때 사용 → "3차원 측정기가 부품 10개를 무인으로 3회씩 자동 측정"
④ 계수형 합치도

합격/불합격 등 정성적 판정

여러 평가자의 육안 판정이 표준(참값) 및 서로 간에 얼마나 일치하는지 검증합니다.

이럴 때 사용 → "외관 검사자 3명의 양품/불량 판정이 믿을만한가?"
⑤ Type4 선형성·치우침

측정 범위 전체의 정확도 검증

여러 기준값(저~고)에 대한 Bias가 범위에 따라 변하는지(선형성)와, Bias 자체가 0인지(치우침)를 각각 검정합니다.

이럴 때 사용 → "저울이 가벼운 것도, 무거운 것도 똑같이 정확한가?"
⑥ 유형1 Gage

게이지 자체의 반복성·치우침 평가

기준값이 있는 시료 1개를 한 측정자가 반복 측정하여, 게이지 단독 성능(Cg/Cgk)을 빠르게 스크리닝합니다.

이럴 때 사용 → "새 게이지를 현장에 투입하기 전 기본 성능부터 확인"

💡 ①·②·③은 공차를 입력하면 %공차까지, 입력하지 않으면 %연구변동·%기여율·ndc로 판정합니다. ⑥은 기준값이 필수이며, 공차를 넣으면 Cg/Cgk 판정까지 계산됩니다.

v2.0 · 잘못된 모듈 선택 방지 — ② 내포연구에 모든 측정자가 같은 부품을 측정한 데이터(=교차 데이터)를 넣으면 이제 오류로 중단됩니다. 이전 버전은 이를 조용히 받아들여 %GRR을 실제보다 좋게 계산했습니다.

Step 2

데이터 입력 — 타이핑하거나 엑셀에서 붙여넣기

입력 표의 열 구성은 선택한 모듈에 따라 자동으로 바뀝니다. 모든 모듈은 1행 = 1개 측정 기준의 세로형(long) 표를 사용합니다.

📊 데이터 입력 — 측정자 / 부품번호 / 측정값
측정자부품번호측정값
1A10.29
2A10.28
3A2-0.56
4B10.08

이 예시는 ① Gage R&R 교차연구 표입니다. 같은 측정자에 여러 부품·여러 반복 행이 있어도 됩니다 — 순서는 상관없이 자동으로 그룹핑됩니다. v2.1 — 열 순서가 측정자 → 부품번호 → 측정값으로 바뀌었습니다(이전에는 부품번호가 먼저였습니다). ② 내포연구도 동일한 순서를 씁니다.

입력 방법

  • 표에 직접 타이핑하거나, 엑셀에서 여러 열을 통째로 복사(Ctrl+C)해서 붙여넣기(Ctrl+V)
  • 열 순서 = 표 상단 헤더 순서와 반드시 일치해야 합니다
  • 모든 모듈이 관측 1건 = 1행인 세로형(long) 표를 씁니다

📥 예제 데이터 불러오기

데이터 입력 카드 우측 상단의 버튼을 누르면, 선택한 모듈에 맞는 예제 데이터가 표에 자동으로 채워집니다. 표 형식을 눈으로 먼저 확인하고 싶을 때 사용하세요.

예제는 형식 확인용 임의 데이터입니다. AIAG 교재의 공표 수치와는 일치하지 않으므로 교재로 교차검증하지 마세요.

v2.0 · 입력 검증 리포트

이전 버전은 잘못된 셀을 말없이 버리거나 값을 바꿔서 분석했습니다. v2.0은 분석 실행 시 제외 대상을 먼저 보여주고 계속할지 묻습니다.

입력 9행 중 5행만 분석에 사용됩니다 (제외 4행). 4행 [측정값] "10,5" — 숫자로 해석할 수 없음 5행 [측정값] "N/A" — 숫자로 해석할 수 없음 6행 [측정값] "10.2 mm" — 숫자로 해석할 수 없음 9행 [측정값] "1,234" — 숫자로 해석할 수 없음 이대로 계속하시겠습니까? [ 확인 ] [ 취소 ]

왜 중요한가 — 이전 버전은 "10,5"를 10으로, "1,234"를 1.234로 경고 없이 바꿔서 계산했습니다. 엑셀 로캘이나 단위가 섞인 셀 하나 때문에 판정이 뒤집힐 수 있었습니다. v2.0은 이런 값을 거부하고 사유를 알려줍니다.

💡 제외된 행 목록은 통계 리포트의 [0] 분석 조건 블록과 PPT 표지에도 함께 기록되어, 나중에 "이 결과가 몇 행으로 나온 것인지"를 추적할 수 있습니다.

④ 계수형 합치도는 wide 그리드로 입력합니다 v2.1

이전 버전은 "평가자·표본번호·평가결과·표준(참값)" 4열을 평가자마다 한 행씩 직접 입력해야 했습니다. v2.1부터는 분석 옵션 카드의 측정자(측정기) 수 · 반복횟수 값에 맞춰 표가 자동으로 아래와 같은 모양으로 생성됩니다 — 두 값을 비워두면 측정자 1 · 반복 3이 기본값으로 적용됩니다.

위는 측정자수=2 · 반복횟수=2일 때의 표 모양입니다. 검사자1, 검사자2… 그룹 라벨은 측정자수에 맞춰 자동 생성되며 이름을 바꿀 수 없습니다(내부적으로 검사자1, 2… 순서로만 구분). 해당 시행을 하지 않은 셀은 공란으로 두면 조용히 분석에서 제외되며(오류 아님), 표본번호가 빈 행이나 응답이 전부 공란인 행만 실행 시 확인창에 안내됩니다.

v2.1 · 옵션을 바꾸면 표가 다시 그려집니다 — 측정자수·반복횟수 값을 바꾸면 표의 열 구성이 새로 짜여집니다. 표에 이미 입력된 값이 있으면 "그리드를 재구성하면 입력된 데이터가 사라집니다. 계속하시겠습니까?" 확인창이 뜨고, [취소]를 누르면 옵션 값과 표가 바뀌기 전 상태로 원복됩니다.

💡 예제 데이터 불러오기를 누르면 측정자수·반복횟수가 예제 데이터에 맞춰(측정자 3 · 반복 2) 자동으로 설정된 뒤 표가 채워집니다.

Step 3

분석 옵션 설정 + 실행

옵션은 선택한 모듈에 따라 다르게 나타납니다. v2.0부터 모듈 선택 카드와 좌우로 나란히 배치되어 한 화면에서 함께 설정합니다.

⚙ 분석 옵션
공차 (USL − LSL, 전폭) : 예: USL 10.15 / LSL 9.85 → 0.30
연구변동 승수 K : 6 (99.73%, AIAG MSA-4 기본)

v2.0 · 공차는 반드시 전폭(USL − LSL) — 편측값(예: ±0.15)을 넣으면 %공차가 정확히 2배로 잘못 계산되어 판정이 뒤집힐 수 있습니다. 라벨과 입력 예시가 전폭임을 명시하도록 바뀌었습니다.

① · ② · ③ Gage R&R 계열

  • 공차 (전폭) — 선택 입력. 넣으면 %공차까지 계산되고, %연구변동과 %공차 중 나쁜 쪽이 최종 판정이 됩니다.
  • 연구변동 승수 K v2.0 신규 — 기본 6(포함확률 99.73%, AIAG MSA-4 · Minitab 기본). 구 사내표준이 5.15(99%)를 쓴다면 선택할 수 있습니다.
K는 %공차에만 영향을 줍니다. %연구변동은 비율이라 K가 약분되어 값이 바뀌지 않습니다. K=5.15는 K=6보다 %공차를 약 14% 작게 표시하므로, 경계 구간에서 판정이 갈릴 수 있습니다.

④ 계수형 합치도

  • 측정자(측정기) 수 / 반복횟수 v2.1 신규 — 데이터 입력 표의 열 구성을 결정합니다. 둘 다 비워두면 측정자 1 · 반복 3이 기본값입니다. 값을 바꾸면 표가 재구성되며, 표에 데이터가 있으면 먼저 확인창이 뜹니다.
  • 순서형(Ordinal) 체크박스 — 평가결과가 "상/중/하"처럼 순위가 있으면 체크 → Kendall 계수가 계산됩니다.
  • 범주 순서 지정 UI v2.0 신규 — 체크하면 감지된 범주가 칩으로 나타나며, ◀ ▶ 화살표로 낮음→높음 순서를 직접 지정합니다.

⑥ 유형1 Gage

  • 기준값(Reference) — 필수. 측정 대상의 공인된 참값입니다.
  • 공차 (전폭) — 선택. 넣으면 Cg/Cgk와 적합/부적합 판정까지 계산됩니다.

⑤ Type4 선형성

v2.0부터 공차 입력이 가능합니다. 넣으면 Linearity 절대값이 함께 산출됩니다(%Linearity는 공차 없이도 계산).

v2.0 · 순서를 지정하지 않으면 위험합니다 — 순서를 지정하지 않으면 문자 정렬이 적용됩니다. Low / Medium / High는 알파벳순이 High < Low < Medium이라 순위가 뒤엉켜 Kendall 계수가 조용히 틀린 값을 냅니다. 순서형을 쓴다면 반드시 순서를 확정하세요 — 지정한 순서는 리포트에도 인쇄됩니다.

5Type4 선형성 및 Gage 치우침 연구

입력 열 : 샘플번호 · 기준값 · 측정값 — 기준값이 서로 다른 여러 샘플을 각각 반복 측정 (AIAG는 5개 이상 수준 권장)

  • 내부적으로 Bias = 측정값 − 기준값을 계산한 뒤 선형성과 치우침을 각각 판정합니다.
  • 선형성 회귀표 : 절편 b0 · 기울기 b1 — 각각 계수·SE·t·P + %Linearity(= 100×|b1|) · Linearity(공차 입력 시) · 적합결여(LOF) 검정 v2.0 신규
  • 치우침 검정표 : 기준값별 + 전체 평균 Bias의 t검정과 95% 신뢰구간 v2.0 신규
  • 분산분석표 : 샘플번호 / 오차 / 총계 (Bias 동질성 검정) + 셀평균모형 요약
  • 차트 : 기준값 대비 Bias 산점도 + 적합선 + 95% 신뢰대 + 기준값별 평균 마커, 샘플번호별 Bias 분포

v2.0에서 가장 크게 바뀐 모듈입니다. 이전 버전은 "샘플번호별 Bias가 서로 다른가"만 검정해서, 전 구간에서 똑같이 크게 치우친 게이지(예: 모든 기준값에서 Bias = +5.0)를 "치우침이 일정합니다"라며 정상 판정했습니다. 이제 치우침을 별도로 검정합니다.

6유형 1 Gage 연구

입력 열 : 측정값 단일 열(25회 이상, 권장 50회) + 옵션에 기준값(필수)·공차(선택) 입력

  • 기초 통계량 : N, 평균, 표준편차, Bias, Bias 95% 신뢰구간, t, df, P v2.0: CI 추가
  • Gage 능력 지수 (공차 입력 시) : Cg, Cgk, %Var(반복성), %Var(반복성+치우침), 적합/부적합 판정
  • 반복이 25회 미만이면 표본 수 경고가 표시됩니다. v2.0
  • 차트 : 측정값 런차트, 측정값 히스토그램

v2.0 · 런차트 관리선 정정 — 관리선이 기준값 ± 10%공차로 바뀌었습니다(Cg/Cgk 판정식이 전제하는 밴드). 이전 버전은 공차 전폭(±공차/2)을 그려 5배 넓었기 때문에, 표에서는 "부적합"인데 그림에서는 모든 점이 여유롭게 들어가 보이는 모순이 있었습니다. 참고용 공차 전폭선은 회색 점선으로 함께 표시됩니다.

모든 측정값이 동일해 표준편차가 0이면 이제 "판정 불가 — 분해능 부족"으로 안내합니다. 이전 버전은 판정 : null 이라는 문자열을 그대로 인쇄했습니다.

두 판정은 독립입니다. 전 구간에서 동일하게 큰 Bias는 "선형성 양호 + 치우침 심각"입니다 — 선형성만 봐서는 절대 잡히지 않으므로 반드시 두 줄을 함께 읽으세요.

⑥ 유형1 Gage — Cg / Cgk

Cg ≥ 1.33 이고 Cgk ≥ 1.33이면 게이지가 해당 용도에 적합합니다. 둘 중 하나라도 미달이면 부적합이며, 특히 Cgk가 낮으면 치우침(Bias)이 원인일 가능성이 큽니다.

Cg = 0.2 × 공차 / (6s) ← 게이지 산포가 공차의 20% 안에 드는가 Cgk = (0.1 × 공차 − |Bias|) / (3s) ← 치우침까지 반영한 능력 런차트 관리선 = 기준값 ± 0.1 × 공차 ← Cg/Cgk가 전제하는 밴드

결과 해석을 위한 용어 가이드

MSA 리포트에 자주 나오는 용어를 짚고 갑니다.

📏EV / AV / GRR / PV

EV(반복성)는 같은 사람이 같은 부품을 다시 재도 생기는 차이, AV(재현성)는 사람이 달라서 생기는 차이입니다. 둘을 합치면 GRR, 부품 자체의 실제 차이는 PV입니다.

📐%연구변동 / %공차 / 승수 K

연구변동(SV)은 K × 표준편차이며, K는 기본 6(포함확률 99.73%, AIAG MSA-4)입니다. 전체 변동 중 해당 성분의 비율이 %연구변동, 공차 대비 비율이 %공차입니다. %연구변동은 비율이라 K와 무관하지만, %공차는 K에 정비례합니다.

🧮%기여율 (%Contribution)

분산 기준으로 각 성분이 총 변동에서 차지하는 비율(100 × 성분분산 / 총분산)입니다. 분산은 더할 수 있으므로 합이 정확히 100%가 됩니다. 판정 기준은 1% / 9%입니다.

🪜ndc (구별되는 범주 수)

측정시스템이 부품 간 차이를 몇 단계로 나눠 볼 수 있는지입니다. 1.41 × (PV / GRR)로 구하며 5 이상이어야 합니다. 이 값이 작으면 부품이 실제로 달라도 측정기가 구별하지 못합니다.

🔀축소모형 (Reduced model)

교호작용(부품×측정자)이 통계적으로 유의하지 않으면, 그 항을 오차에 합쳐 다시 계산하는 것이 AIAG·Minitab 방식입니다. v2.0은 이를 자동으로 적용하고 리포트에 명시합니다.

🤝Kappa / Fleiss' Kappa

우연히 일치할 확률을 제외하고 실제로 얼마나 일치하는지를 나타내는 지수입니다. 1에 가까울수록 완벽히 일치, 0에 가까우면 우연 수준입니다. Cohen's κ는 평가자 대 표준, Fleiss' κ는 평가자들 사이의 일치도를 봅니다.

📊Kendall's W / tau-b

W는 순서형(상/중/하 등) 평가에서 여러 평가자의 순위가 얼마나 일관되는지를 0~1로 나타냅니다. tau-b는 평가결과와 표준의 순위 상관계수입니다. 둘 다 동점(tie) 보정이 적용됩니다.

🎯Bias / 선형성 / %Linearity

Bias는 측정값과 기준값의 차이입니다. Bias가 측정 범위에 따라 달라지면 선형성 문제이고, Bias 자체가 0이 아니면 치우침 문제입니다 — 서로 다른 결함입니다. %Linearity는 회귀 기울기의 절댓값×100으로, 통상 10% 미만을 요구합니다.

🚨미검출률 β / 과검출률 α

계수형 검사에서 β는 실제 불량을 양품으로 놓친 비율(≤2%), α는 실제 양품을 불량으로 판정한 비율(≤5%)입니다. β가 고객 유출로 직결되므로 가장 엄격하게 봅니다.

⚙️Cg / Cgk

Cg는 게이지의 산포(반복성)가 공차 대비 충분히 작은지, Cgk는 산포뿐 아니라 치우침(Bias)까지 반영한 지수입니다. 실무에서는 Cgk가 더 엄격한 기준입니다.

📎Clopper-Pearson 신뢰구간

합치도 백분율의 95% 신뢰구간을 구하는 정확 이항 방식입니다. 표본이 적을 때 구간을 무리하게 좁히지 않아, 실제보다 정밀해 보이는 착시를 막아줍니다.

FAQ

자주 묻는 질문

"균형설계가 필요합니다" 오류가 떠요▸
① 교차연구는 모든 부품×측정자 조합의 반복수가 동일해야 하고, ② 내포연구는 측정자마다 담당 부품 수가 동일해야 합니다. 데이터 중 일부 조합의 측정 횟수가 다르면 이 오류가 나타납니다. 표를 다시 확인해 빠지거나 초과된 행이 없는지 점검하세요.
공차(Tolerance)를 입력하지 않으면 어떻게 되나요?▸
①·②·③ 모듈은 %공차 열 없이 %연구변동·%기여율·ndc로 판정합니다. ⑥ 유형1 Gage는 기준값만 필수이고 공차는 선택입니다 — 공차가 없으면 Cg/Cgk 없이 기초 통계량과 치우침 검정만 제공됩니다.
공차는 ±값을 넣나요, 전체 폭을 넣나요?▸
반드시 전체 폭(USL − LSL)입니다. 예를 들어 규격이 10 ± 0.15라면 0.30을 넣어야 합니다. ±0.15를 넣으면 %공차가 정확히 2배로 계산되어, 30% 경계에서 판정이 그대로 뒤집힙니다.
연구변동 승수 K는 6과 5.15 중 뭘 써야 하나요?▸
특별한 사유가 없으면 6(기본값)을 쓰세요. AIAG MSA 4판과 Minitab의 기본값이며 포함확률 99.73%에 해당합니다. 5.15(99%)는 MSA 3판까지의 값으로, 사내 표준서가 5.15로 명시된 경우에만 선택하세요. K는 %공차에만 영향을 주며 %연구변동은 바뀌지 않습니다.
계수형 합치도 분석에서 평가자를 여러 명 넣으려면?▸
v2.1 분석 옵션 카드의 측정자(측정기) 수에 원하는 평가자 수를 입력하세요. 그 수만큼 "검사자1, 검사자2…" 열 그룹이 표에 자동으로 생성됩니다. 같은 평가자가 같은 표본을 여러 번 판정했는지 보려면 반복횟수를 그 횟수만큼 입력하면 됩니다(해당 그룹 안에 Try#1, Try#2… 열이 생김).

둘 다 비워두면 기본값(측정자 1 · 반복 3)이 적용되고, 값을 바꾸면 표가 자동으로 다시 그려집니다(입력된 데이터가 있으면 먼저 확인창이 뜹니다).
"내포연구는 측정자마다 서로 다른 부품이어야 합니다" 오류가 떠요▸
모든 측정자가 같은 부품을 측정한 데이터를 내포연구 모듈에 넣은 경우입니다. 이 데이터는 ① 교차연구로 분석해야 합니다.

v2.0 이전에는 그대로 통과되어 %GRR이 실제보다 좋게 나왔습니다(예: 17.08% → 11.84%).
교차연구·내포연구·유형3, 뭐가 다른가요?▸
측정자가 여럿이고 모두 같은 부품을 측정할 수 있으면 ① 교차연구, 측정하면 샘플이 파괴되어 측정자마다 서로 다른 부품을 측정해야 하면 ② 내포연구, 측정자가 결과에 영향을 주지 않는 설비(자동측정기 등)라면 ③ 유형3입니다. 유형3은 재현성 항이 없고 반복성만 평가합니다.
순서형 데이터인데 Kendall 계수가 안 나와요▸
Kendall 계수는 순서형 3수준 이상에서만 산출됩니다. 양품/불량 같은 2범주 데이터에서는 순위 개념이 성립하지 않아 계산하지 않고, 그 사유가 리포트에 표시됩니다. 3수준 이상이라면 [순서형] 체크 후 범주 순서(낮음→높음)를 반드시 지정하세요.
"판정 불가 — 분해능 부족"이 나왔어요▸
유형1에서 모든 반복 측정값이 동일(표준편차 0)할 때 나타납니다. 계산 실패가 아니라 중요한 부적합 신호입니다 — 게이지의 측정 눈금이 공차에 비해 너무 거칠다는 뜻입니다. AIAG는 측정 증분이 공차의 5% 이하일 것을 권고합니다. 더 정밀한 게이지가 필요합니다.
Type4에서 "치우침 존재"인데 "선형성 양호"라고 나와요▸
모순이 아닙니다. 선형성은 "Bias가 측정 범위에 따라 변하는가", 치우침은 "Bias가 0인가"로 서로 다른 질문입니다. 전 구간에서 똑같이 +5.0 치우친 게이지는 선형성은 완벽하지만 치우침은 심각합니다. 두 판정 줄을 반드시 함께 읽으세요.
입력한 행 수와 리포트의 N이 달라요▸
필수 항목이 비었거나 숫자로 해석할 수 없는 셀이 있으면 그 행은 제외됩니다. v2.0은 분석 실행 시 제외 대상과 사유를 먼저 보여주고 계속할지 묻습니다. 제외 내역은 리포트의 [0] 분석 조건 블록에도 기록됩니다.

"10,5"(쉼표 소수점), "10.2 mm"(단위 포함) 같은 값이 흔한 원인입니다.
예제 데이터는 실제 데이터인가요?▸
아닙니다. 표 형식과 결과 화면을 미리 보여주기 위한 임의 샘플입니다. AIAG 교재의 공표 수치와는 일치하지 않으므로 교재를 펴놓고 교차검증하지 마세요. 실제 분석 시에는 표 내용을 실제 측정값으로 교체해서 사용하세요.
결과를 발표 자료로 만들고 싶어요▸
분석 실행 후 결과 대시보드 탭 우측 상단의 [💾 PPT 보고서 저장]을 누르면 PPT가 자동으로 다운로드됩니다. 표는 편집 가능한 네이티브 표로, 차트는 원본 비율 그대로 들어가며, 모든 슬라이드에 툴 버전과 분석 일시가 기록됩니다. 화면을 그대로 뽑으려면 Ctrl+P 인쇄도 지원합니다.
인터넷이 안 되는 PC에서 열면 어떻게 되나요?▸
이 툴은 표·차트·PPT 라이브러리를 외부 CDN에서 내려받으므로 폐쇄망에서는 동작하지 않습니다. v2.0은 이 경우 빈 화면 대신 "필수 라이브러리를 불러오지 못했습니다" 안내 화면을 표시합니다. 오프라인 사용이 필요하면 관리자에게 오프라인 배포본을 요청하세요.
